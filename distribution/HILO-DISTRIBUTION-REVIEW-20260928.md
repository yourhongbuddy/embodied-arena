Status: research and packaging only. No directory submission, social publication, paid promotion, install, vote, star, acceptance, or deployment is claimed by this document.

## Official primary-source checks

- **OpenAI Plugins Directory** — https://developers.openai.com/plugins/deploy/submission. Skills-only plugins remain eligible for the universal directory shared by ChatGPT and Codex. Public submission requires Apps Management write access, a verified developer or business identity, public website/support/privacy/terms materials, realistic starter prompts, five positive tests, three negative tests, and review before publication. HILO remains draft-not-submitted.
- **Custom GPTs** — https://help.openai.com/en/articles/8554397-creating-and-editing-gpts and https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq. Personal Free/Go/Plus/Pro accounts still cannot create or publish new GPTs. Custom GPTs are scheduled to retire December 11, 2026, with February 11, 2027 only for qualified Enterprise workspaces with an approved deferral. HILO should continue targeting Plugins rather than a new GPT Store listing.
- **Claude plugin distribution** — https://code.claude.com/docs/en/plugins/publish. Anthropic now documents both repository-hosted marketplaces and a public directory submission path. Directory submission reaches claude.ai, Cowork and Claude Code, requires a GitHub-hosted plugin and a paid claude.ai plan, and requires local strict validation plus install testing before submission. HILO already has a repository marketplace package but has not been submitted to Anthropic's public directory.
- **Skills.sh** — https://skills.sh/docs. Discovery remains driven by genuine CLI installations from public skill sources; leaderboard placement is not a manual submission surface.
- **Official MCP Registry** — https://registry.modelcontextprotocol.io/ and https://registry.modelcontextprotocol.io/docs. The registry is a server-metadata registry with publish/auth/validate surfaces. HILO's current public package is skills-only; no MCP Registry submission is claimed.
- **Hugging Face Spaces** — https://huggingface.co/docs/hub/spaces-overview. Public Spaces expose code, are clonable, and can provide a reproducible synthetic demo. No paid Space or account action is authorized here.
- **Rebind** — no current official publishing documentation was independently recovered today beyond previously recorded package/review requirements. Do not assume the legacy Rebind publishing route is unchanged and do not submit.
