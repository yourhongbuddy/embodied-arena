# HILO synthetic intervention audit — staging only

This is a **local, explicitly synthetic** six-event illustration of disclosed versus undisclosed human assistance. Click the button to compare the false zero-assistance declaration with a corrected 45-second declaration. It does not run the canonical WANTED scorer, certify a robot, verify consent, collect real-world data, or infer field hours. There are no uploads, external assets, cookies, analytics, or network/API/model calls.

## Reproduce locally

Open `index.html` in a browser or static-file viewer. The illustrative fixture is embedded; no services or credentials are needed, and a plain-language explanation remains with JavaScript disabled. Run `python3 -m unittest discover -s tools -p 'test_hilo_static_demo.py' -v` from the repository root for offline source-integrity checks.

The frontmatter matches the official [Hugging Face Static Spaces documentation](https://huggingface.co/docs/hub/spaces-sdks-static). **This is candidate packaging, not a published Space.** Before any public redistribution, obtain the owner's license and publisher authorization, verify account/terms, run a real-browser smoke test, and retain actual submission/listing receipts. No paid compute is necessary or authorized.
