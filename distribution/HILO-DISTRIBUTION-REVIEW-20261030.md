## Practical packaging decision

The official ChatGPT/Codex Plugins Directory submission guide (https://developers.openai.com/plugins/deploy/submission) continues to support skills-only plugins. The current HILO `plugins/hilo-benchmark` remains a skills-only draft, **not submitted**. The publisher must confirm verified identity/organization rights, license, primary icon, required skill scans, provider installation tests and applicable policy attestations. Adding an MCP server to an **already published skills-only** plugin is not currently supported. The HILO owner must decide scope *before* the first submission. A listed plugin requires review and a later publisher action; uploading a ZIP does not imply publication. Fees are not established; **no spending authorized**.

The official GPT Help Center (https://help.openai.com/en/articles/8554397-creating-and-editing-gpts) was updated around October 30 and continues to state that personal Free, Go, Plus and Pro accounts **cannot create/publish new GPTs**. New GPT creation ended October 26, 2026 for affected Enterprise workspaces (FedRAMP exception); these restrictions do not establish the user's actual plugin publishing rights. Do not assume the legacy GPT Store is a valid fallback.
