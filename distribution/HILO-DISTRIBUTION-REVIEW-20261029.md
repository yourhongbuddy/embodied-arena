## Materially clarified eligibility

- **OpenAI skills-only Plugins Directory:** https://developers.openai.com/plugins/deploy/submission and https://developers.openai.com/plugins/plugin-guidelines — skills-only packages are an eligible format, but may have *additional* listing eligibility requirements. Organization owner or Apps Management Write, verified developer identity, matching public metadata, completed skill scans, applicable review and policy attestations are needed. A primary icon is required for submission. **Important packaging decision:** an MCP server cannot currently be added to an *existing skills-only* plugin; if a future server is required, plan the initial package accordingly rather than promising an in-place upgrade. HILO's current package is skills-only, not submitted. Fees/account billing: not established; no spend authorized.
- **Personal GPT Store:** https://help.openai.com/en/articles/8554397-creating-and-editing-gpts — new personal Free/Go/Plus/Pro GPT creation/publishing unavailable. Official current guidance says affected Enterprise workspaces also stopped new GPT creation on **2026-10-26** (FedRAMP exception). This is **not** a substitute distribution channel.
- **Hugging Face Static Spaces:** https://huggingface.co/docs/hub/en/spaces-overview — static HTML Spaces remain free; new Gradio/Docker compute Spaces generally require an eligible paid subscription. A functioning, license-cleared, synthetic-only *static* validator would be appropriate only after account authorization and actual local browser tests. No Space created.
- **Skills.sh Packs:** https://www.skills.sh/docs/packs — a Vercel sign-in creates packs; installation needs no user authentication; packs are unlisted, **not access-controlled**, and valid SKILL.md frontmatter is required. The publicly visible source package and license still need review. No installs or pack created.
