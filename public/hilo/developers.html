Questions that matter

Can 100 robots running for 100 hours prove 10,000-hour retention?

No. Aggregate exposure does not establish the unobserved long-horizon retention curve. Use the current canonical protocol and report the supported horizon.

Does the skill upload private home recordings?

The package does not contain an upload service or automatic telemetry. Keep private recordings in an authorized environment and check the data practices of any host tools you choose.

How do I contribute?

Start with a reproducible integration issue or a methodological counterexample in the project's own repository. Do not post private records, credentials or unverifiable performance claims.
